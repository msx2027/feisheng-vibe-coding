| # | 洞 | 现象（修法前） | 修法 | 突变验证 |

| 1 | `--scope` 指向不存在的面 | 静默 `continue` → 打「扫描 0 个文件…命中 0 处」exit 0 | `existsSync` 判不过 → **exit 2** 并打印解析后的绝对路径 | 单测断言 `code==2` 且 `doesNotMatch(/命中 0 处/)` |

## 5 ②：下游登记门的两档设计

`provenance/DOWNSTREAMS.json`（新建，schema `vibe-coding-skills/downstreams@1`）登记：

- `block`：生成器路径、版本常量名、起始标记正则全文、入口文件清单；
- `scan`：`depth` 3 与 `skipDirs`；
- `census`：可照抄的普查命令 ＋ 当次读数 `146／28／14` ＋ 为什么不做成常驻步（`census.cost`）；
- `downstreams`：4 个真实根，逐根逐入口写 `blockVersion` 与标记行里的 `checksum`，并写 `runtimeRegistry` 布尔；
- `excluded`：2 个前缀（worktree 分身、golden-path 夹具），各带完整理由。

`scripts/check-downstream-registry.mjs` 退出码 **2＝门没跑成／1＝判红／0＝一致**，两档：

- **结构档**（`--structure-only`，verify 5l 常驻）：登记文件存在且合法、清单非空、字段形状、根与前缀都是绝对路径、
  入口都是根内相对名、版本方向 vs 生成器常量、登记的标记正则**就是生成器源码里那一条完整正则字面**（两端锚定＋三个命名组齐备）、
  入口清单与 `TARGET_FILES` 同源、排除项带理由且不与登记面重叠、`mutable` 标了、普查命令含由该正则取出的完整标记串、
  `-maxdepth` 不浅于 `scan.depth`、读数齐备且与登记表自身的条目数相符。
- **盘上档**（verify 可选步 `-IncludeDownstreamDisk`）：逐根逐入口比对标记行的 `version`／`checksum`、
  标记里的 `file=` 与登记名一致、一根一文件只许一处起始标记、根内不得冒出未登记的带块入口、
  `.vibe-runtime.json` 在不在与登记一致（按根一条），排除前缀必须还在、稳定排除面必须真排除到东西、
  易逝排除面里不得出现 `.vibe-runtime.json`，走树读不动就 exit 2，最后做**稳定面闭合**。

为什么盘上档不能进常驻：CI 是 `ubuntu-latest`（`.github/workflows/release-gate.yml:13`），没有 `E:/` 与 `G:/`。
塞进常驻只有两条路——让 CI 永久红，或者「盘够不到就当没有下游」，后者正是本包这两天在拆的「空判即绿」。
所以拆成两档，各步的名字与读数写清自己判什么，`docs/HANDOFF-NEXT.md` 的验收命令一并带上第三个开关。

判据归属边界（刻意不在本门实现，避免第二套判定逻辑）：块正文的 checksum 到底等不等于本代渲染结果，
归 `init-target-runtime.mjs --check／--strict`；本门只判「标记行写着什么 vs 登记着什么」。
同理，**同一版本号在不同根哈希不同**只作读数不作判红——目标项目的运行时名／入口文件名字段本就允许不同，
拿它当版本谎会误报；真要抓版本谎的是上面那条 `--check`。

## 8 门禁接线与数字同步

- `scripts/verify.ps1`：新增 5l「下游登记对账（结构档）」、5m「下游登记对账单测」两个常驻步，
  与新开关 `-IncludeDownstreamDisk` 的可选步「下游登记盘上对账」（5n）。默认 **29 → 31** 步，全开 **31 → 34** 步
  （可选步由末步自扫 `if ($Include…)` 行现算，实测 3 个）。
- 5l 额外钉**三条**自证：读数必须含「登记 N 根、排除前缀 M 个」，结构档绿而根数 < 1 一律判失败（本门不得用

5. **排除面的根数按前缀各自 `dirname` 去重后相加**，跨前缀理论上能重复计。不修的依据是「前缀重复登记」与
   「前缀嵌套」两条红已经把这条路堵死（本轮各补了一条用例钉着），前提成立时各前缀命中集互不相交，相加即全局去重。
   这是本批第一次出现「不修的理由靠新增用例而不是靠文字保证」。
6. **README 英文句只锚步数、不锚开关清单**：三个 `-Include*` 的名字在那一行仍是手抄。扩锚点要把整串开关名进正则，
   收益小于把步数进锚点，留给下一批（此处如实挂着，不假装已覆盖）。
7. **fs-agent 那份陈旧生成器副本**（缺口二）不在本包改：本包只补了通用防线（降级硬拦 5k），副本本体归该项目维护；
   本批对它全程只读。
