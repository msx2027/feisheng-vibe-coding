唯一入口被触发：feisheng-vibe-coding

整个系统只有一个项目级入口。宿主加载它，得到第一条指令：「读控制面协议，按启动协议执行，不许跳过控制面直接回答」。

SKILL.md（入口 + 启动动作）已实测：纯中文首动作即触发
2

控制面接管（项目的大脑）

读取控制面协议 → 先确认「项目当前的真实状态」和「这次授权的边界」→ 再决定怎么做。它是唯一拥有路由、任务深度、风险、真源、验收定义的组件。

governance/sliver-core/SKILL.mdreferences/runtime-adapter.md
3

选主路由（22 选 1）

运行控制面自带的确定性路由工具，从 22 条主路由里精确选一条（如 立项 / 需求澄清 / 功能开发 / 代码审计 / 测试验收 / 部署发布），再查这条路由的投影拿到执行细节。

runtime_decision_contract.py route-catalogroute-projection
4

需要时叠加"透镜"（8 选 0~n）

只有当前端、数据、安全、部署等受影响时，才加载对应的条件透镜（如安全透镜、数据透镜），决定额外的检查动作。普通小任务一个透镜都不加载，避免小题大做。

lens-catalog / lens-projection
5

按路由委派内部技能（38 个，四组）

控制面按「什么条件加载哪个能力」的委托表，把具体活儿分给对应技能；技能只交回结果和发现，永远不能自己改路由或项目真源。

6

执行 + 新鲜验证

按路由干活（写代码 / 出规格 / 跑测试 / 发版…），完成前必须拿出新鲜的验证证据——没有当次验证，不许宣布"完成/安全/可发布"。

控制面验收门测试策略 T0–T4
7

向用户交付，写回 durable 真相

用大白话汇报结果和证据；确认过的关键决定写回项目真源（需求文档 / 开发计划 / 验收记录），供下一轮使用。

8

经验沉淀（自动 + 手动）

你在对话里纠正 AI（"不对，你搞错了"）会被自动记录到目标项目的经验索引；会话启动时提醒待消化的经验；也可以手动"规则淘金"，把重复踩的坑固化成规则。

Hook：SessionStart / UserPromptSubmit（白名单内写入）rule-harvester

🛡 全程的安全护栏（每一步都在生效）

fail-closed：任何组件拿不准就拒绝，不猜；写入白名单：Hook 只能写经验索引和状态目录，越界即拒绝； 真源唯一：需求/计划/术语/验收各只有一个写入者，杜绝两套账；权限边界：安全审计只读，动代码要你授权； 新鲜验证：没有当次证据，禁止宣称完成。

生命图 一个商用级产品的生命周期，和每个阶段背后的技能

从「我有个想法」到「上线运营」再回到「下一个迭代」——每个阶段由控制面委派对应技能承接，形成闭环。

① 想法 / 立项

控制面「立项」路由：问题库访谈、项目模板、任务深度与授权边界

② 需求 / 规格

product-spec-builder（深挖对话→开发级规格）
requirements-test-designer（需求→验收/测试设计）

③ 设计方向

design-brief-builder（采访式收设计需求→设计简报）
brand · design-system（品牌与体系）

④ 架构落地

architecture-foundation（范围/边界/数据/权限落真源，PASS 才动工）
codebase-design（模块与接口词汇）

⑤ 开发计划

dev-planner（读需求和设计简报 → 分阶段开发计划）

⑥ 编码实现

dev-builder（搭骨架/按 Phase 编码/集成验证）
tdd（测试先行）· impeccable 族 12 个（UI 视觉与交互）
进入验收与发布

⑦ 测试 / 审查

test-automation（E2E/回归）
code-review · audit · critique · harden · optimize

⑧ 发布上线

release-builder（构建-打包-测试-发布，隐私与漏洞检查）

⑨ 运行 / 修 bug

bug-fixer（大白话报障→分级修复）
diagnosing-bugs（疑难缺陷证据阶梯）
hotspot-governor（大文件治理）

⑩ 迭代维护

doc-sync-guardian（文档防漂移）
ui-system-guardian（UI 债务治理）
回到 ②：下一个功能迭代

⑪ 经验沉淀（贯穿全程）

Hook 自动采集纠错信号 → 经验索引
rule-harvester（规则淘金/固化）
演化信号 → 提议新规则或新技能
经验反哺下一轮（越用越懂你的项目）
贯穿全程的两条底线：控制面是唯一的"大脑"（技能只交结果，不抢方向盘）；每个阶段完成都要有当次验证证据。
