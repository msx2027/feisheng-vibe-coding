# 浏览器验收防骗手册（browser-acceptance）

> 用浏览器做视觉/交互验收时，环境本身会撒谎：旧代码、别人的实例、无头渲染差异、瞬态空屏。
> 来源：目标项目实机教训（2026-09 fs-agent 开发期，验收通道反复出假绿/假红）。
> polish 收口做 Final Verification 前，命中下列场景先读本手册。

## 1. 通道选择

- **headless 自证不算数**：视觉真源验证必须在真实桌面壳里做；同版本内核的 headless 渲染不能替代。
- **自起第二个 dev 实例与壳实例缓存互不相通**：watcher 漏改时会出现"半新半旧"错位；touch 源文件强制重转换可救。
- **内嵌浏览器（IAB）的滚动通道全部无效**：滚动类界面验收走 CDP 驱动或真人验收。

## 2. 端口与实例归属（先验明正身，再信读数）

- **复用已占用端口的 dev 服务器前，先 curl 探特征/模块 URL 验代码归属**：该端口可能供着别的 worktree 的旧代码，跑出来的是假失败/假通过。
- **起 CDP 取证 Chrome 前先 curl 探调试端口占用**：Chrome 端口被占时**静默不绑**，CDP 会连到并行会话的浏览器实例，看到的是别人会话的页面。
- **截图验收先复用已热加载的占用端口 dev 服务器**（curl 探到特征确认归属后），不要盲目新起实例。

## 3. CDP 驱动语义

- **导航必须用 `page.goto()`**：CDP `openPage` 不收 URL 参数，传了也**静默忽略**——白屏就是这么误诊的。
- **`waitFor` 参数按表达式插值**：裸选择器字符串在表达式语境里恒为真，等待形同虚设；传 `querySelector(...)` 表达式。
- **CDP 诊断临时 profile 放系统 Temp**：放进 vite 监视目录会 EBUSY 崩掉 dev server。

## 4. 假阴与假阳

- **空白瞬态不是缺陷**：先 `waitFor` 目标条件等挂载完成并复跑一次，再定性。
- **截图对比防伪差异**：先等字体就绪（防 FOUT 假差异）；交互动作同批连续执行。
- **视觉态断言**：DOM 逐字节对比先剥 style 再比；focus-visible 走查用真实键盘 Tab；读 transition 属性先等动画完成。
- **CSS 级联失效文本断言查不出**：reduce 关闭规则的特异性必须 ≥ 生效规则；属性别挂在与生效规则同元素的复合选择器上；最终用浏览器实读 computed 值兜底。

## 5. 证据纪律

- **证据目录有默认值的，重跑必须显式传参**：默认值可能指向旧批目录——曾发生重跑覆盖历史截图（checkout 还原补救）。
- **验证派生物自动更新（sync/watch/hook）要用域内真实内容变更做探针**：mtime 触碰与文档类改动对索引器等于无变更；"mtime 没动"不等于"机制失效"。

## 6. 桌面壳（WebView2）通道

- **浏览器级 CDP attach 在 WebView2 会挂起**：真壳验收改用页面级 WebSocket 直连壳内 webview 的调试端口，不走浏览器级 attach。
- **取证用独立 `WEBVIEW2_USER_DATA_FOLDER`**：默认用户数据目录被壳实例占用时，探针实例静默起不来——表象是"门禁脚本坏了"，实际是通道根本没起来。
- **取证用的临时改动必须还原并核对零 diff**：壳 devUrl、调试口等取证临时改动，取证结束立即还原，并用 `git diff` 确认源码零残留；带着取证配置跑出来的验收读数不作数。
- **环境干扰要读数化**：并发会话重编译压住同屏区域这类环境干扰，把"输入可达性闸门 + 页面地址"写进验收读数——环境问题必须以读数现形，不许伪装成功能缺陷。
