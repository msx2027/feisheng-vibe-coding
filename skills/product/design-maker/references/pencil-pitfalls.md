# Pencil 画布操作暗礁（pencil-pitfalls）

> 处理 `.pen` 文件时的操作级坑位清单。来源：目标项目实机教训（2026-09 fs-agent 开发期反复触发的画布类返工）。
> 只讲"手会踩的坑"，设计决策本身仍以 SKILL.md 的原则为准。

## 1. 节点 id 生命周期

- **跨步骤引用节点只用已存 id**：execute 跨步骤引用节点时传早前返回的真实 id；凭"新起一个名字"定位会拿到 undefined 路径并**静默空转**（不报错、不生效）。
- **复制板与母板的同名字节点 id 不同**：要改"某一块板"的元素前，必须在**目标板子树内重新定位 id**；禁止复用早前在别的板次收集的 id——容器 id 同样失效。
- **回调取值层级**：元素树遍历回调里读的是 `el.props` 层，不是元素对象顶层。

## 2. 替换与收编：先盘点，再动手

- **替换一块区域**：先枚举父容器的**全部可见子节点**，逐一禁用/删除，再截图确认；只隐藏同名容器会漏掉直接子级残留。
- **母件化收编**：先对全文档做一次同构 visitor 盘点（含复制板私带的副本），再动手收编；只按目标板清单收编必漏。
- **部件系统性偏短/偏小 = 先查母件**：毛病多半在母件写死的默认值上，只改实例必复发；改母件前盘点全部实例，评估波及面。

## 3. 坐标系换算

- **画布 frame 尺寸 = 外沿**：换算成前端壳宽时必须按 border-box 换算（画布标 375 含边框，CSS 内容宽可能只有 373），并且**实测外沿**验证，不信换算纸上对。
- **帧内坐标读数钉 left 锚定的帧原点**：auto 居中只在容器同宽时才与 left 锚等价，两者不可混读。
- **拉伸容器内的子元素用中心锚点**：`left: k% + translateX(-50%)`；用左缘百分比定位时偏移是 `(k-1)×半宽`，容器一拉伸就漂（同坑三踩）。
- **渲染坐标 ≠ 存储坐标**：绝对定位子件的渲染坐标对存储坐标存在**每件不同的恒定偏移**。实测差值后补偿存储值，并在卷内登记偏移量防误改。

## 4. 核验方式

- **文字级改动用 2x 导出 PNG 核验**：缩略截图看不出小字错误。
- **CJK 垂直居中按字形校准**：中文字形在行框内天然偏下，行框居中后文字仍显靠下；需上移 1–2px（顶部 padding 比底边少），并以放大截图目检。

## 5. 排障口径

- **布局"幽灵缝"**：裸实例也复现的错位 = 容器怪病，不是属性写错。整段照抄健康同构容器替换，不要逐属性纠缠。
