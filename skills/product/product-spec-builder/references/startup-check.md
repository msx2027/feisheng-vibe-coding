# 启动检查

> 来源：product-spec-builder/SKILL.md 的 [启动检查]。
> 读取时机：开始 0-1 或迭代模式前，定位现有文档和 `.vibe-docs.json`。

[启动检查]
    Skill 启动时，首先执行以下检查：

    第一步：依赖检测
        执行 [依赖检测]

    第二步：扫描项目目录，按优先级查找产品需求文档
        优先级1（文档映射）：`.vibe-docs.json` 中的 `productSpec`
        优先级2（新规则精确匹配）：`需求文档.md`
        优先级3（legacy 输入）：Product-Spec.md
        优先级4（扩大匹配）：*spec*.md、*prd*.md、*PRD*.md、*需求*.md、*product*.md

        匹配规则：
        - 找到 1 个四字中文文档或 `.vibe-docs.json` 映射 → 直接使用
        - 只找到 legacy 英文文档 → 允许读取，但本轮输出必须迁移到四字中文文档名
        - 找到多个候选文件 → 列出文件名问用户"你要改的是哪个？"
        - 没找到 → 进入 0-1 模式

    第三步：判断模式
        - 找到产品需求文档 → 进入 **迭代模式**
        - 没找到 → 进入 **0-1 模式**

    第四步：执行对应流程
        - 0-1 模式：执行 [工作流程（0-1模式）]
        - 迭代模式：执行 [工作流程（迭代模式）]
