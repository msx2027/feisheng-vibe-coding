# 功能设计文档索引

这个目录只放一句话装不下的功能设计文档。每份文档由 `truth-capture.md` 的授权卡触发创建，并同时在功能清单中链接。读取时按本索引或当前任务的 owner 闭包打开对应文件，不整目录读取。

## 索引

| 功能 | 文档 | status | 影响 owner | 最后变更 |
| --- | --- | --- | --- | --- |
| @@功能名称@@ | [@@feature-id@@.md](@@feature-id@@.md) | `active` | @@owner 路径@@ | @@YYYY-MM-DD@@ |

## 规则

- `status` 取 `active | superseded | archived`；默认视图只列 `active`。
- 一个功能一份文档；同一 owner 关切被拆成多份小文档时合并，一份文档覆盖多个无关关切时拆分，两者都经 `truth-capture.md` 的授权卡。
- 归档只由 `整理开发资料` 在用户批准后移动到本目录下 `archive/`；归档不是删除。
- 目录深度不超过两层；按 `architecture.md` 的模块拆分子目录时，每层一份索引。
- 不在索引中的文档视为不可发现，结构门禁会报告。
