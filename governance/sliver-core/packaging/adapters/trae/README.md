# Trae Adapter Status

Trae remains an experimental target. This directory intentionally contains no runtime overlay.

Do not publish a Trae bundle or claim first-class support until all of these are current and verified:

1. Official skill discovery and install contract.
2. A clean bundle containing no Codex-only metadata.
3. Fresh-session discovery and representative behavior evidence.
4. Upgrade and removal instructions tested on the target version.
