# 技能包与目标项目范围混淆

**问题描述**：用户要求在当前 vibe-coding-skills 中增加“开工前架构地基”的 Skill 能力时，AI 误解为需要给 zmyy/目标项目新增系统架构或开工确认文档。

**触发场景**：在技能包仓库中处理新增 Skill 能力的请求时，错误地将技能包改动外溢到目标项目。

**教训/建议**：先明确改动对象和边界。用户指定“当前技能包”时，默认只修改技能包源码、镜像或其文档；除非用户明确授权，不创建、修改或规划任何目标项目文档与内容。
