# 验收记录

## 文档职责

本文记录需要用户真实点击、操作或观察才能确认的验收项。

自动化验证、AI 自查和用户人工验收必须分开记录。没有用户明确确认前，不得把人工验收写成通过。

目标不是让用户反复测试同一个功能，而是把已经确认过的范围沉淀下来：后续开发先做影响分析和自动化回归，只有自动化无法覆盖时才提醒用户复验受影响路径。

## 状态枚举

| 状态 | 含义 |
| --- | --- |
| `不适用` | 本节点没有需要用户真实点击 / 操作 / 观察确认的内容 |
| `待用户验收` | 自动化验证和 AI 自查已完成，但还需要用户真实验收 |
| `用户已确认` | 用户已明确确认验收范围，并已记录确认依据 |
| `需回归复验` | 后续改动可能影响已确认范围，且自动化不能完全覆盖 |

## 交付提醒格式

每次命中人工验收触发规则时，交付必须包含：

- 需要用户真实点击的路径：
- 自动化已覆盖：
